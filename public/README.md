# Wuxing Zhanjiang Website Screenshots

Put your screenshot files **directly in this `public/` folder** (not in a subfolder).

Required filenames (lowercase `.png` extension):

- `screenshot_1.png` — Gameplay Level 6
- `screenshot_2.png` — Card Playing Battle
- `screenshot_3.png` — In-game Shop

When you run `npm run build`, Vite copies these files into `dist/` (e.g. `dist/screenshot_1.png`).

Then run `npm run deploy` to publish the built site to GitHub Pages.
