# Wuxing Zhanjiang Website Screenshots

Put your screenshot files here before building. They should be named:
- `screenshot_1.png` (Gameplay Level 6)
- `screenshot_2.png` (Card Playing Battle)
- `screenshot_3.png` (In-game Shop)

When you run `npm run build`, Vite will automatically copy these files into the `dist/` directory root (e.g. `dist/screenshot_1.png`), making them accessible at the root of your domain.
